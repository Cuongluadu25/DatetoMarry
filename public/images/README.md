# Ảnh của Giang

Thả ảnh vào thư mục này với đúng tên file. Ảnh là tùy chọn — vị trí nào chưa có
ảnh thì website vẫn hiển thị ảnh hoa gốc (hoặc placeholder), không báo lỗi giao diện.

| File | Vai trò | Tỷ lệ khuyến nghị |
| --- | --- | --- |
| `giang-main.jpg` | Ảnh duy nhất, khung lớn giữa gallery | 4:5 dọc, ~1200 × 1500px |
| `giang-01.jpg` | Thay ảnh hồng ở phần lời chào 20·10 | 4:5 dọc |
| `giang-02.jpg` | Thay ảnh hồng ở lời chúc 02 | 4:5 dọc |

Ghi chú:

- Chỉ dùng ảnh do bạn tự cung cấp. Trang không tải ảnh từ dịch vụ ngoài, không
  API, không upload đi đâu cả.
- Nếu ảnh bị cắt lệch khuôn mặt, chỉnh `object-position` (hoặc `--gallery-pos`)
  trong `css/style.css` để chọn điểm neo.
- Nên nén ảnh dưới ~400KB mỗi tấm để trang mở thật nhanh.
