# Ảnh của Giang

Thả đúng **một** ảnh vào thư mục này với tên file `giang-main.jpg`. Nếu chưa có
ảnh, website tự hiển thị khung placeholder "A special place for Giang’s photo"
và không báo lỗi.

| File | Vai trò | Tỷ lệ khuyến nghị |
| --- | --- | --- |
| `giang-main.jpg` | Ảnh duy nhất, khung lớn giữa gallery | 4:5 dọc, ~1200 × 1500px |

Ghi chú:

- Chỉ dùng ảnh do bạn tự cung cấp. Trang không tải ảnh từ dịch vụ ngoài, không
  API, không upload đi đâu cả.
- Nếu ảnh bị cắt lệch khuôn mặt, chỉnh `--gallery-pos` trong `css/style.css`
  (ví dụ `--gallery-pos: 50% 25%;`) để chọn điểm neo.
- Nên nén ảnh dưới ~400KB để trang mở thật nhanh.
